# 🍽️ Project Name: Foodians

**Foodians** is a community-driven food review platform where users can explore, share, and discover amazing food experiences from restaurants, street vendors, and homemade dishes.

🌐 **Live Site:** https://b12-foodians-client-a10.netlify.app/

---

## 🚀 Features

* ⭐ Users can **add, edit, and delete food reviews** with ratings and images
* ❤️ **Favorite system** to save preferred foods for later
* 🔍 **Search functionality** using MongoDB `$regex` to find foods by name
* 🔐 **Authentication system** with Email/Password and Google login (Firebase)
* 📊 **Dynamic featured & recent reviews** based on rating and date
* 📝 **User-specific dashboard** (My Reviews & My Favorites)
* 🎯 Responsive and modern UI with smooth user experience
